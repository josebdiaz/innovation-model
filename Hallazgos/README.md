# Hallazgos del equipo

Aquí cada integrante publica lo que encuentra y puede mejorar el Modelo CLAVE: un referente, una pregunta mal planteada, un dato de Delirio, una idea para el taller. Todo lo aprobado lo leen las IA conectadas al repositorio, así que alimenta el trabajo de todos.

## Cómo publicar uno

1. Pídele a tu IA que redacte el hallazgo con la [plantilla](_plantilla.md).
2. En GitHub, entra a tu carpeta → **Add file → Create new file**. Nombre corto en minúsculas y con guiones: `indice-andi.md`.
3. Pega el texto → **Commit changes…** → deja marcada la opción de crear una rama nueva y abrir un pull request → **Propose changes** → **Create pull request**.
4. Avisa en el WhatsApp del equipo.

El paso a paso, con el nombre de cada botón, está en la [guía de conexión](https://josebdiaz.github.io/innovation-model/Contexto/guia-conexion-equipo.html#paso-3). Si GitHub se te enreda, mándale el texto a Jose por WhatsApp.

## Qué pasa después

Jose revisa en máximo 48 horas, asigna un código (`H-001`, `H-002`…) y registra la decisión en [registro.md](registro.md): **integrado**, **parcial**, **en espera** o **descartado**, siempre con la razón. Si el hallazgo cambia el modelo, el [CHANGELOG](../CHANGELOG.md) lo cita.
