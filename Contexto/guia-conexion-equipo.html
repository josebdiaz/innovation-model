Guía de conexión al repo

Todo el proyecto vive en un solo lugar. Con esta guía conectas tu IA a ese lugar para que trabaje con el mismo contexto que el resto del equipo, y aprendes a enviar tus hallazgos para que alimenten el modelo. No necesitas saber programar.

Leer todoDocumento Ancla, modelo, preguntas y notas de clase.
Publicar lo tuyoCada quien tiene su carpeta de hallazgos.
Integrar con revisiónJose revisa cada envío antes de que entre al modelo.

Tres palabras y listo

GitHubLa página web donde guardamos el proyecto. Es como una carpeta compartida que recuerda cada cambio.
RepositorioNuestra carpeta en GitHub: josebdiaz/innovation-model. La IA lee de aquí.
Pull requestUn envío para revisión. Así mandas un hallazgo: Jose lo revisa y lo aprueba.

1Acepta la invitación

  1. Si no tienes cuenta en GitHub, créala gratis en github.com/signup y mándale tu nombre de usuario a Jose por WhatsApp.
  2. Busca en tu correo el mensaje de GitHub que dice que Jose te invitó a innovation-model.Si no aparece, revisa la carpeta de spam o promociones.
  3. Abre el mensaje y pulsa View invitation, luego Accept invitation.
  4. Listo: ya puedes ver el proyecto en github.com/josebdiaz/innovation-model.
No puedes dañar nada.

La versión principal del proyecto está protegida: ningún cambio entra sin que Jose lo revise.

Si la invitación venció o no llegó

Escríbele a Jose por WhatsApp con tu usuario de GitHub y te la reenvía.

Claude

Conexión directaSe actualiza con un clic
  1. En claude.ai, abre Proyectos y crea uno nuevo llamado Modelo CLAVE.
  2. En la parte del conocimiento del proyecto, pulsa + y elige GitHub.
  3. Autoriza el acceso con tu cuenta de GitHub cuando te lo pida.
  4. Busca y elige josebdiaz/innovation-model. Claude guarda una copia del proyecto.
  5. Cuando Jose avise de cambios, abre el proyecto y pulsa el botón de sincronizar del repositorio.La copia no se actualiza sola.
Plan B

Si no ves la opción de GitHub, sigue el camino del ZIP de la sección de ChatGPT y sube los archivos al conocimiento del proyecto.

ChatGPT

Archivos en un proyectoFunciona en cualquier plan
  1. Abre el repositorio, pulsa el botón verde Code y elige Download ZIP.
  2. Abre el ZIP en tu computador para descomprimirlo.
  3. En ChatGPT, crea un proyecto llamado Modelo CLAVE.
  4. Sube al proyecto estos archivos de la carpeta descomprimida:
    • Documento_Ancla_Tareas_y_Seguimiento.md
    • README.md
    • Modelo/CHANGELOG.md y Modelo/V0/README.md
    • Modelo/V0/elementos/modelo-clave.json
    • Modelo/V0/bateria-v0.csv
    • Logs_Clase_Sesion_1_Haciendolo_Posible.md
  5. Cuando Jose avise de cambios, baja el ZIP otra vez y reemplaza los archivos que cambiaron.

Gemini

Importar en el chatSolo desde el computador
  1. Abre gemini.google.com en el computador y empieza un chat nuevo.
  2. Pulsa + y elige Importar código.
  3. Pega esta dirección: https://github.com/josebdiaz/innovation-model.El repositorio es público, así que no tienes que vincular tu cuenta de GitHub.
  4. Haz tus preguntas en ese mismo chat. En un chat nuevo hay que importarlo otra vez.
Límites

Un repositorio por chat, hasta 5.000 archivos y 100 MB. Nuestro proyecto cabe sin problema.

3Publica tus hallazgos

Un hallazgo es algo que aprendiste y que puede mejorar el modelo: un referente, una pregunta mal planteada, un dato de Delirio. Va un archivo por hallazgo, en tu carpeta.

Hallazgos/jose/Hallazgos/kate/Hallazgos/mar/Hallazgos/paola/Hallazgos/jorge-mario/

Pídele a tu IA que lo redacte

Redacta un hallazgo para el Modelo CLAVE con la plantilla de la carpeta Hallazgos. Mi hallazgo es: [escribe aquí lo que encontraste y de dónde viene]. Antes de entregarlo, revisa que cumpla las reglas del profesor: una sola idea por pregunta, que respete la simetría 5 pilares × 3 factores × 3 preguntas, que hable de hechos observables y que no sesgue el modelo hacia una sola industria.

Súbelo desde el navegador

  1. En el repositorio, entra a Hallazgos y luego a tu carpeta.
  2. Pulsa Add file y elige Create new file. Ponle un nombre corto, por ejemplo indice-andi.md, y pega el texto que redactó tu IA.
  3. Pulsa Commit changes…. En la ventana que se abre, deja marcada la opción de crear una rama nueva y empezar un pull request.GitHub crea la rama solo. No tienes que hacer nada más con ella.
  4. Pulsa Propose changes y luego Create pull request.
  5. Avisa en el WhatsApp del equipo que subiste un hallazgo.
Qué pasa después

Jose lo revisa en máximo 48 horas. Cada hallazgo recibe un código y una de estas decisiones, siempre con la razón:

IntegradoParcialEn esperaDescartado

Cuando un hallazgo cambia el modelo, el historial de versiones lo cita. Así queda claro qué aportó cada integrante.
