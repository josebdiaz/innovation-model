# Gestión del proyecto

| Archivo | Qué contiene |
|---|---|
| [`documento-ancla.md`](documento-ancla.md) | Hoja de ruta, matriz de tareas T-01 a T-15, criterios del profesor y bitácora de reuniones |
| [`decisiones.md`](decisiones.md) | Registro de decisiones con alternativas y razones |
| [`Reuniones/`](Reuniones/) | Una carpeta por reunión del equipo (`Sync-1/`, `Sync-2/`…) con su plan de acción |

Para cada reunión nueva: crea `Reuniones/Sync-N/`, guarda ahí el plan de acción y agrega una fila en la bitácora del Documento Ancla.
