# 08 · Reglas de redacción

1. **Un hecho por pregunta.** Ningún ítem une dos hechos con "y", "o", "ni" ni "además". Los listados solo aparecen como ejemplos entre paréntesis.
2. **Observable.** Cada ítem describe algo que se puede ver o verificar: un documento, una reunión, una licencia, una frecuencia.
3. **Respuesta única.** Si alguien pudiera responder "sí a una parte y no a la otra", el ítem se divide.
4. **Dos referentes.** Hechos de la organización con "Delirio"; conductas cotidianas con "mi equipo" o "mi jefe directo".
5. **Variables contemporáneas.** 7 ítems de IA y trabajo digital: C3.3, A1.2, A1.3, A3.1, A3.2, A3.3, V2.3.

Ejemplo de corrección: "¿Los líderes inspiran y dan presupuesto?" → "¿Los líderes inspiran?" + "¿Hay presupuesto para probar?"
