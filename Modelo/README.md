# Modelo CLAVE

| Carpeta | Qué contiene |
|---|---|
| [`V0/`](V0/) | Versión vigente: deck, one-pager, ficha técnica, plan de backend, paleta, auditoría WCAG, batería y [elementos separados](V0/elementos/) |
| [`_exploraciones/`](_exploraciones/) | Variantes descartadas que se conservan como referencia (V1 con vocabulario del show) |

La carpeta `V0/` agrupa la generación 0 del modelo. Las versiones `0.x.y` no crean carpetas nuevas: se marcan con etiquetas de Git y se describen en el [historial de versiones](../CHANGELOG.md). Una carpeta `V1/` solo aparece si cambia la estructura del modelo (versión mayor).
